# Taobao visual copy pack

## Visual direction

Tone: professional, restrained, executive-report style.

Avoid:

- cartoon robot;
- exaggerated money graphics;
- "guaranteed growth";
- dense technical screenshots.

Use:

- clean white/black/blue-gray palette;
- report cover mockup;
- dashboard-like metric cards;
- short boss-facing promises;
- privacy and human-review badges.

## Detail page section sequence

### 1. Problem

标题：

> 你不是缺数据，是缺能串起来看的人

正文：

订单表、库存表、广告消耗、退款记录分散在不同后台。老板每天看很多数字，但真正需要的是：哪里变差了，为什么变差，下一步先查什么。

### 2. What this service does

标题：

> 我交付的不是模板，是一份可复核的经营诊断

四张卡片：

- 整理数据：订单 / 广告 / 库存 / 退款
- 梳理口径：收入 / 退款率 / 客单价 / ROI
- 发现异常：退款偏高 / ROI 偏低 / 滞销库存
- 给出动作：今天查什么 / 三天改什么 / 一周验证什么

### 3. Report sample

标题：

> 报告会清楚标注证据和不确定项

展示字段：

- 客户问题
- 关键指标
- 诊断发现
- 证据
- 建议动作
- 人工确认
- 边界声明

### 4. Package pricing

标题：

> 先做小诊断，再决定要不要长期搭建 AI 经营助手

价格卡：

- 199：AI 经营体检，1 个问题，1 张表，1 页摘要。
- 699：标准诊断报告，最多 3 张表，完整报告。
- 1999：AI 经营助手体验版，报告 + 7 天陪跑。

### 5. Privacy and boundaries

标题：

> 数据安全和结论边界，比“AI 很厉害”更重要

要点：

- 请先删除手机号、姓名、地址、微信号等个人信息。
- 报告只基于客户提供数据和确认口径。
- 不承诺保证增长，不替代财税法专业意见。
- 数据不足时会明确写“不足以判断”。

### 6. Order flow

标题：

> 下单后怎么交付

流程：

1. 你提交一个经营问题。
2. 我确认数据是否适合分析。
3. 你提供脱敏后的导出表。
4. AI 生成初步诊断草稿。
5. 人工复核口径和结论边界。
6. 交付经营诊断报告。

## Trust badges

- AI 辅助，人工复核
- 证据链交付
- 支持 Excel/CSV
- 不夸大承诺
- 先判断是否适合
- 可匿名沉淀案例

## Customer-facing microcopy

- “如果数据不够，我会告诉你缺什么，而不是硬编结论。”
- “老板不需要再多看一张表，老板需要知道下一步先查哪里。”
- “先做一次小诊断，验证有用后再考虑长期 AI 助手。”
- “经营分析不是玄学，结论必须回到数据、口径和业务常识。”
