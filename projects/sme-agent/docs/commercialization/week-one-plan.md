# Week-One Launch Plan

## Day 1 — Offer and proof assets

Outcome:

- Confirm first buyer profile.
- Confirm first SKU title, packages, and non-promises.
- Create data-intake checklist.
- Create report outline.
- Publish the first Xiaohongshu post.

Product work:

- Add a `diagnosis report` use case to SME Agent docs.
- Use current metadata grounding as the backbone: terms, metrics, dimensions, tables, entities, and knowledge references.

Human work:

- Provide Taobao publishing screenshots.
- Choose first industry and package price.

## Day 2 — Demo case

Outcome:

- Create a synthetic but realistic "revenue decline" case.
- Produce one public-safe sample diagnosis report.
- Extract 3 Xiaohongshu posts from the sample case.

Product work:

- Add sample CSV schemas.
- Add a report assembler that can render metadata-grounded findings.

Human work:

- Review whether the sample feels like a real small-business pain.

## Day 3 — Taobao listing

Outcome:

- Product listing draft ready.
- FAQ and disclaimers ready.
- First SKU can be submitted if platform category and rules allow it.

Product work:

- Add order-intake template and customer project folder convention.

Human work:

- Confirm category, after-sales wording, and delivery method in backend.

## Day 4 — Delivery workflow

Outcome:

- One order can be processed end-to-end manually with LLM assistance.

Product work:

- Add report-generation command or script.
- Add evidence manifest for each customer delivery.

Human work:

- Validate final report quality.

## Day 5 — Growth scripts and CRM

Outcome:

- 5 Xiaohongshu posts.
- DM qualification script.
- Simple customer tracker.

Product work:

- AICO daily asks Lead, Growth Writer, Product Manager, Challenger, and Reviewer for a short operating brief.

Human work:

- Reply to real DMs and record objections.

## Day 6 — Seed users

Outcome:

- Contact at least 10 target users.
- Offer 3 discounted or free diagnosis slots in exchange for anonymized feedback.

Product work:

- Turn every real objection into a backlog item or FAQ.

Human work:

- Decide which customers are acceptable; reject unsupported requests.

## Day 7 — Public launch

Outcome:

- Taobao listing live or ready for review.
- Xiaohongshu has at least 5 posts.
- One public-safe sample report.
- One delivery SOP.
- One AICO weekly review report.

Decision:

- If there is customer interest: prioritize delivery automation.
- If there is traffic but no DMs: adjust content positioning.
- If there are DMs but no orders: adjust offer and price.
- If there are orders but delivery is slow: productize intake and report assembly first.
