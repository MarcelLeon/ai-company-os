# Visual assets

- `assets/taobao-main-premium.svg`: premium trust main image.
- `assets/taobao-main-pain.svg`: pain-driven main image.
- `assets/taobao-detail-preview.svg`: long detail-page preview.
- `assets/exported/taobao-main-premium.png`: exported premium trust PNG, 800 x 800.
- `assets/exported/taobao-main-pain.png`: exported pain-driven PNG, 800 x 800.
- `assets/exported/taobao-detail-preview.png`: exported detail preview PNG, 900 x 1800.

Xiaohongshu cover assets:

- `assets/xiaohongshu/*.svg`: seven editable cover SVGs.
- `assets/xiaohongshu/exported/*.png`: seven exported cover PNGs, 1080 x 1440.

## Usage

Open the SVG files in a browser or design tool, then export to PNG/JPG according to the actual Taobao/Qianniu upload requirements.

## Design intent

- Executive-report feel, not cartoon AI.
- Clean blue-gray palette to signal reliability.
- Emphasize evidence, human review, and privacy boundaries.
- Avoid guaranteed-growth language.

## Recommended first upload set

1. Main image: `taobao-main-premium.svg`
2. Secondary image: `taobao-main-pain.svg`
3. Detail image: `taobao-detail-preview.svg`

If the platform requires square-only images, split the detail preview into three square images:

1. problem and service value;
2. report sample and package pricing;
3. privacy boundary and order flow.
