## Recommended first post

Title:

```text
这场直播比上一场差，不一定是没人买
```

Body:

```text
很多团队复盘直播间，会直接问：
"是不是这场没人买？"

但我见过更危险的情况：
支付订单数没变，支付买家数也没变，最后支付 GMV 还是掉了。

这通常说明问题不在"有没有人买"，而在：
1. 买了更便宜的 SKU；
2. 高客单 SKU 没承接住；
3. 支付金额口径变了；
4. 退款或优惠把实际收入吃掉了。

所以我做两场直播对比时，不先给鸡汤建议。

我会先拆：
- 哪场直播；
- 哪个主播；
- 哪些 SKU；
- 支付 GMV 差额；
- GPM 差额；
- 订单数和买家数有没有一起变。

只有拆到实体，复盘才有动作。

我现在做一个直播电商 AI 经营诊断内测：
先看字段够不够，再回答"这场为什么比上一场差"。

字段不够，我会直接告诉你缺什么；
字段够，再做一页老板能看懂的归因报告。
```

CTA:

```text
私信「两场对比」，我发你需要导出的两个表。
也可以加微信 17610788906，备注「两场对比」。
```

## First comment

```text
我先放一个字段自查：
1. 两场直播的场次 ID；
2. 每场订单支付金额；
3. 商品/SKU；
4. 退款金额；
5. 匿名买家 ID。

这些字段够了，才能先判断是"没人买"、"客单变低"、"SKU 结构变了"，还是"支付/退款口径问题"。
```

## Keyword reply

When someone comments or DMs `两场对比`:

```text
可以，我先不让你发完整后台。

你先准备两张表的字段名就行：
1. 直播场次表：场次 ID、日期、主播、观看人数；
2. 订单支付表：场次 ID、商品/SKU、订单状态、支付金额、退款金额、匿名买家 ID。

先发字段名或脱敏样例，不要发手机号、姓名、地址。
字段够，我再建议你是否做 199 小体检。
```

## First 24-hour operating checklist

```text
[ ] Publish the post.
[ ] Save the post link.
[ ] Add the first comment within 10 minutes.
[ ] Reply to every relevant comment.
[ ] DM keyword users within 12 hours.
[ ] Move qualified users to WeChat.
[ ] Record every lead with keyword, pain, fields, score, and next action.
[ ] Offer 199 only after the user has a real question and enough fields.
[ ] Record every objection as future content.
```

## Success signal

The first post is useful if it produces any of:

- `3` keyword comments or DMs.
- `1` WeChat add with the right remark.
- `1` user willing to send field names.
- `1` objection that can become the next post.

Do not judge the campaign by likes alone.
