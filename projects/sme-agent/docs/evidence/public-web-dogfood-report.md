## 初步发现

### 退款率偏高，需要拆商品、主播话术和履约原因

- 证据：支付口径退款率为 17.0%。
- 建议动作：先按商品、直播场次、承诺话术和售后原因拆分，不要只看总 GMV。
- 人工确认：确认是否包含仅退款、退货退款和售后赔付。

### GPM 偏低，直播流量成交效率需要复盘

- 证据：当前 GPM 为 398.97，即千次观看支付 GMV。
- 建议动作：复盘流量来源、商品排序、讲解节奏和福利品承接，优先提升有效观看到支付的链路。
- 人工确认：确认观看人数是曝光、进入直播间还是有效观看，避免口径错配。

### 支付转化率偏低，需检查流量和商品匹配

- 证据：观看到支付买家的转化率为 0.1%。
- 建议动作：用直播间停留、商品点击、加购和支付漏斗继续定位断点。
- 人工确认：确认 buyer_id 已匿名且能稳定去重。

## 必须人工确认

- 确认平台 GMV 是否包含未支付、取消或退款订单。
- 确认观看人数口径是曝光、进入直播间还是有效观看。
- 确认支付金额是否包含运费、优惠券、平台补贴。
- 确认 buyer_id 已替换为不可逆匿名 ID。
