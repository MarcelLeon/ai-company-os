# Xiaohongshu Week-One Content Plan

## Positioning

我用 AI 帮中小企业老板把订单、库存、客户、广告和财务数据翻译成能行动的经营诊断。

## Daily post structure

1. One concrete owner pain.
2. One common wrong reaction.
3. One simple analysis frame.
4. What AI can help with.
5. A low-pressure CTA.

## Seven posts

### 1. 很多小老板不是不会经营，是没人把数据翻译成人话

CTA: 如果你也有订单表、库存表、广告表，但不知道怎么看，可以私信“诊断”，我先帮你判断适不适合做。

### 2. 收入下降时，别先怪流量，先查这 5 个指标

Frame: order count, average order value, refund rate, repeat purchase, channel mix.

### 3. 库存积压不是仓库问题，很多时候是经营数据没人看

Frame: slow-moving SKU, gross margin, ad spend, stock age, sales velocity.

### 4. 广告投放亏钱，老板最该问的不是 ROI，而是利润口径

Frame: spend, orders, refunds, gross margin, repeat purchase.

### 5. 中小企业请不起数据分析师，可以先做一个 AI 经营诊断

Frame: data intake, metric definitions, diagnosis report, human review.

### 6. 你的 Excel 不是乱，是缺一个经营问题

Frame: start from "why revenue dropped" instead of "analyze all data".

### 7. 一个 AI 经营诊断报告应该长什么样？

Frame: conclusion, evidence, assumptions, risks, next actions.

## Comment and DM script

Opening:

> 你可以先不用买。我先问 5 个问题，判断你的数据适不适合做 AI 经营诊断。

Questions:

1. 你主要做什么业务？
2. 最近最想解决收入、客户、库存、投放里的哪个问题？
3. 你手上有没有最近 3 个月订单/客户/库存/广告数据？
4. 数据现在是什么形式：Excel、后台导出、数据库，还是截图？
5. 你希望拿到一页诊断，还是完整经营分析报告？

Qualification:

- Good fit: has recent structured data and a concrete business question.
- Maybe: has data but no clear question; sell entry diagnosis.
- Not fit: only wants guaranteed growth, has no data, or asks for regulated financial/tax/legal advice.
